# Media Library

All media assets for the vision-guided MORL thesis, organized by reference paper. Downloaded from each project's official website (Aug 2, 2026). Videos are MP4 (H.264, `ftyp` verified); images are PNG/JPG/GIF.

- **Total:** 145 files / ~960 MB across 13 folders
- **Empty folders:** `demo-enhanced-morl/`, `gcr-ppo/` (YouTube-only videos; blocked by bot verification, download manually)
- **Path convention:** `media/<paper-name>/`
